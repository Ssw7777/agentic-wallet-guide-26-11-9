# 06 · 操作习惯清单

技术决定下限，习惯决定你活多久。

---

## 每日（5 分钟）

### 早上：看板巡检

- [ ] 打开看板，看总资产有没有异常波动（±10% 以上要查原因）
- [ ] 看有没有"待领取 / 待退回"的仓位到期
- [ ] 看 BNB 余额够不够今天要付的 gas
- [ ] 看有没有不明来源的转出（**最重要的安全信号**）

### 晚上：收工对账

- [ ] 今天的交易哈希都记下来了吗
- [ ] 领回的币/BNB 到账了吗（receipt status + 余额复核）
- [ ] 明天有哪些仓位到期，记在日历上
- [ ] 今天有没有"情绪化操作"（追高、加仓、FOMO）

---

## 每周（15 分钟）

- [ ] **备份钱包目录**（加密后传到离线位置）
- [ ] 复核授权：把不需要的 `allowance` 清成 0
- [ ] 检查自动化：有没有忘了关的定时任务

  ```bash
  systemctl list-timers --all
  crontab -l
  ps -ef | grep -E "bot|mint|loop" | grep -v grep
  ```

- [ ] 清理粉尘：把没价值的代币归拢，减少看板噪音
- [ ] 更新自己的"项目账本"：投了多少、回了多少、还压着多少

---

## 每月

- [ ] 全面对账：链上余额 vs 自己记账，差异逐笔查
- [ ] 复盘：这个月赚/亏在哪，哪些是运气，哪些是能力
- [ ] 调整策略：把亏钱的项目砍掉，别"回本就跑"式自我安慰

---

## 每次交易前（30 秒自检）

回答完这四个问题再点执行：

1. **这笔交易最坏情况亏多少？**（gas + 滑点 + 归零）
2. **我模拟过了吗？**（simulationCode = 000000000）
3. **余额够吗？交易后还剩多少 gas？**
4. **地址对吗？**（前后 4 位核对）

答不上来就别点。

---

## 三个"永远不要"

### 1. 永远不要"看到余额就自动打满"

```python
# ❌ 绝对不要
if balance > 0:
    mint_all(balance)

# ✅ 正确
print(f"余额 {balance}，预计可打 {n} 份，等待人工确认")
```

### 2. 永远不要把所有钱放一个项目

> 一个项目崩了，你还能吃饭；所有项目一起崩，你就只能吃土。

建议：单项目投入 ≤ 总资金 20%。

### 3. 永远不要在"关不掉"的自动化里跑真金白银

任何自动化上线前先问：**我能在 30 秒内停掉它吗？**
不能就别上。

---

## 心态：把钱包当"公司"而不是"赌场"

| 赌场思维 | 公司思维 |
|---|---|
| 看到热点就冲 | 先算预期收益和回本周期 |
| 亏了加仓摊平 | 亏了止损，记录原因 |
| 赚了梭哈下一个 | 赚了提取本金，用利润玩 |
| 天天盯盘 | 每天看一次看板 |
| 相信"内部消息" | 只信链上数据和合约代码 |

```markdown
## 2026-01-01
- 项目：XXX
- 操作：mint 5 份，花费 0.015 BNB
- 到期：01-02 12:00
- 预期：约 $2 的代币
- 实际：领回 0.015 BNB + $1.7 代币
- 复盘：押金可退，风险低；但代币流动性差，实际变现 $0.9
- 教训：下次先看池子深度再算"账面收益"
```

坚持记 30 天，你会比 90% 的人更清楚自己在做什么。
